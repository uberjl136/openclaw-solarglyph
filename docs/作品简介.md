## 定稿

工业厂区屋顶光伏在方案阶段要算「一年发多少电、余热回收多少」，目前靠人工套公式，慢且无法复现；通用智能体又不会算。

我们基于开源智能体框架 OpenClaw（MIT，未改其底层源码）新增垂直 Skill「光伏余热仿真」，配自研仿真服务，经 HTTP 对接。

在 OpenClaw 网页说一句「启动光伏余热仿真」，智能体即自主读取技能、调用工具、下发任务、轮询并取回结果、汇总成报告，形成闭环。

实测 5MWp 厂区年发电 499.5 万 kWh、余热回收 315.2 万 kWh、减排 CO₂ 1776 吨，可复现。

代码以 MIT 开放于 github.com/uberjl136/openclaw-solarglyph，含公式溯源文档。
