### 推送仓库（唯一需要你动手的网络操作）

构建环境无法通过 TLS 直连 github.com，因此推送必须在你自己能访问 GitHub 的机器上完成：

```bash
git clone -b feature/solar-glyph-simulation openclaw-solarglyph.bundle openclaw-solarglyph
cd openclaw-solarglyph
node scripts/push-to-github.cjs https://github.com/<你的账号>/<仓库名>.git
```

推送后把链接填进 `docs/technical-report.md` 的**附录 2**，再执行 `npm run report` 重新生成报告。

### 技术报告可随时重新生成

报告是**代码生成**的，改动内容后一条命令即可重出 PDF，并自动校验页数与体积：

```bash
cd work/solarglyph-skill
npm run report          # md → 打印就绪 HTML → A4 PDF，并校验 ≤15 页 / ≤10MB
```

- 正文源文件：`docs/technical-report.md`
- 生成产物：`deliverables/技术报告.pdf`、`deliverables/技术报告.html`
- 当前结果：**13 页 / 0.83 MB，均在限制内**（留 2 页余量）
- 需团队填写的两处占位：**团队名称**与**参赛编号**（位于 `scripts/report/md-to-html.mjs` 的封面区块，以及系统内填写的作品名称如与报告不一致请同步）

## 三、必须避开的红线

1. **公平性（规则三·九）**：技术报告、演示视频、答辩 PPT 及其他评审材料中
   **不得出现学校名称、学校 LOGO、指导教师信息**。
2. **不得只换场景**：规则明确「不得仅通过更换行业场景、简单调用通用模型或组合现成工具形成作品」。
   → 报告必须把「自研 Skill + 自研仿真服务 + 算法溯源」讲清楚，与"直接部署开源项目"划清界限。
3. **许可证要说准**：OpenClaw 是 **MIT**（`LICENSE` 文件为准，GitHub 页面标 `NOASSERTION` 是工具误判），
   在清单里如实填写并说明义务履行情况。
4. **AI 使用要披露（规则三·七）**：报告须说明生成式 AI / 智能体辅助开发的用途、参与环节，
   以及团队的审核、修改、验证与来源权利核查工作。
5. **不得提交凭据**：不要上传 API 密钥、账号密码等（规则三·十一）。

## 四、《开源及第三方资源使用清单》必需字段

大纲给出的参考表列为：

| 序号 | 资源名称及类型 | 版本/来源 | 许可证/授权类型 | 使用/开放方式 | 关键义务/限制 | 团队自主修改或开发内容 | 合规状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |

填写说明要点：

- **资源类型**：开源软件 / 模型 / 数据集 / 框架 / 组件 / 工具 / 素材 / 第三方服务。
- **许可证/授权类型**：开源许可证 / 开放许可 / 模型许可 / 数据许可 / 服务条款 / 其他授权。
- **关键义务/限制**：署名、LICENSE/NOTICE、再分发、源代码提供、衍生作品许可、使用范围。
- **合规状态**：`已核验` / `待核验` / `不适用`。
- **重要提示**：公开可访问 ≠ 当然具有复制、训练、改编或再分发授权。

> 现有 `docs/opensource-inventory.md` 的字段与上表不完全一致，**需按此表重排后再作为报告附录**。

## 七、按优先级该做什么

**必须做（缺了直接判不合格或丢大分）**

1. 到 `www.aicomp.cn` 完成报名并缴费，确认能在系统里选择「AI+开源」主题赛。
2. 把仓库推到 GitHub（当前只有本地 git；推送步骤见 `README.md` 第七节），
   并确认链接在评审期内持续有效，附安装部署说明。
3. 按附件 2 大纲把技术报告写成 PDF（≤15 页、≤10 MB），
   **重点写满「实现完成度与可验证效果」（25 分）与「AI 与开源融合」（20 分）**。
4. 按参考表重排《开源及第三方资源使用清单》并作为报告附录。
5. 录 3—5 分钟 MP4 演示视频。
6. 通篇自查学校名称/LOGO/指导教师信息，确认一处都没有。

**建议做（影响观感与分数）**

7. 用 `docs/verification-evidence.md` 的数据做一张"实测效果"表放进报告。
8. 在报告里如实写一段 AI 辅助开发说明（用途 + 团队审核核查）。
9. 截图佐证：Skill 被识别为 `✓ ready`、仿真服务的任务历史、终端轮询进度。

**晋级后才需要**

10. 答辩 PPT（PDF）。
