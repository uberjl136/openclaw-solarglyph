## 三、技术报告怎么生成

报告是**代码生成**的，改内容后一条命令重出 PDF，并自动校验页数与体积：

```bash
cd work/solarglyph-skill
npm run report
```

- 正文源文件：`docs/technical-report.md`
- 生成到：`work/aic-req/`（**故意不放进仓库**，避免大文件污染提交历史）
- 当前结果：**13 页 / 0.84 MB，均在限制内**（留 2 页余量）
- 生成的 PDF 需要**手动上传到大赛报名系统**

### 需要团队补的两处占位

1. **团队名称**与**参赛编号** —— 在 `scripts/report/md-to-html.mjs` 的封面区块里改
2. 报告**附录 2 的仓库链接** —— 已填好当前仓库地址，如更换仓库请同步

## 四、必须避开的红线

1. **公平性（规则三·九）**：技术报告、演示视频、答辩 PPT 及其他评审材料中
   **不得出现学校名称、学校 LOGO、指导教师信息**。
2. **不得只换场景**：规则明确「不得仅通过更换行业场景、简单调用通用模型或组合现成工具形成作品」。
   → 报告必须讲清「自研 Skill + 自研仿真服务 + 算法溯源」，与"直接部署开源项目"划清界限。
3. **许可证要说准**：OpenClaw 是 **MIT**（以仓库 `LICENSE` 文件为准；GitHub 页面标 `NOASSERTION` 是工具误判），
   在清单里如实填写并说明义务履行情况。
4. **AI 使用要披露（规则三·七）**：报告须说明生成式 AI 辅助开发的用途、参与环节，
   以及团队的审核、修改、验证与来源权利核查工作。
5. **不得提交凭据**：不要上传 API 密钥、账号密码等（规则三·十一）。

## 五、《开源及第三方资源使用清单》必需字段

官方大纲给出的参考表列：

| 序号 | 资源名称及类型 | 版本/来源 | 许可证/授权类型 | 使用/开放方式 | 关键义务/限制 | 团队自主修改或开发内容 | 合规状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |

填写说明要点：

- **资源类型**：开源软件 / 模型 / 数据集 / 框架 / 组件 / 工具 / 素材 / 第三方服务。
- **许可证/授权类型**：开源许可证 / 开放许可 / 模型许可 / 数据许可 / 服务条款 / 其他授权。
- **关键义务/限制**：署名、LICENSE/NOTICE、再分发、源代码提供、衍生作品许可、使用范围。
- **合规状态**：`已核验` / `待核验` / `不适用`。
- **重要提示**：公开可访问 ≠ 当然具有复制、训练、改编或再分发授权。

> 已按此表列重排，内容见技术报告**附录 1**（`docs/technical-report.md`）。

## 六、评分构成（总分 100）

| 评分项 | 分值 | 拉分要点 |
| --- | --- | --- |
| 问题与场景价值 | 15 | 说清真用户、真场景、真问题 |
| **创新性与方案设计** | 20 | 技术组合/流程/场景的**明确创新**；「模板复制、简单部署、界面包装」得 0—6 分 |
| **AI 与开源融合** | 20 | 资源来源、版本、许可证、**自研边界**、关键义务、融合方式说全 → 14—20 分 |
| **实现完成度与可验证效果** | **25** | 完整可运行 + 演示清晰 + **可核验的效果数据/对比结果/社区贡献记录** |
| 开放成果与复用价值 | 15 | 有实际价值且权利边界清晰的代码/插件/文档 + 使用说明 + 维护计划 |
| 材料规范与表达 | 5 | 完整、清晰、规范，能说明团队实际工作 |

同分时依次比较：**实现完成度与可验证效果 → AI 与开源融合 → 创新性与方案设计**。

## 八、按优先级该做什么

**必须做（缺了直接判不合格或丢大分）**

1. 到 `www.aicomp.cn` 完成报名并缴费，确认系统里能选「AI+开源」主题赛。
2. 仓库已推送（见第二条第 8 项）。**确认评审期内链接持续有效**。
3. 生成技术报告 PDF 并上传（`npm run report` → `work/aic-req/技术报告.pdf`）。
4. 录制 3—5 分钟演示视频，按 `docs/recording-web-ui.md` 的五段流程。
5. 通篇自查学校名称/LOGO/指导教师信息，确认一处都没有。

**建议做（影响观感与分数）**

6. 把 `docs/verification-evidence.md` 的实测效果表放进报告。
7. 报告里如实写一段 AI 辅助开发说明（用途 + 团队审核核查）。
8. 截图佐证：网页里 Skill 显示 `ready`、仿真服务的任务记录、网页对话跑出结果的画面。

**晋级后才需要**

9. 答辩 PPT（PDF）。
