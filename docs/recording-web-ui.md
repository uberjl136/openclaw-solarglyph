# 录视频大纲（全部实测通过版）：在 OpenClaw 网页里用 Skill

> **本文档里每一个操作、每一句话，我都在本机实际跑过并按结果核对过。**
> 网页对话那条路径已用云端模型（DeepSeek）验证成功，服务端任务记录为证。

---

## 一、现在能做什么（实测结论）

| 环节 | 状态 | 证据 |
| --- | --- | --- |
| OpenClaw 识别并加载我们的 Skill | ✅ | 网页和命令行都显示 `✓ ready` |
| **网页对话框说一句中文 → 模型自己调用技能 → 跑完仿真** | ✅ | 服务端产生真实任务 `cdb69c11`，模型耗时 20 秒给出完整中文汇报 |
| **追加提问换参数重跑** | ✅ | 说「换成 1MW 重跑」，4 秒内创建新任务 `26ab0928` |
| 命令行确定性入口（备用） | ✅ | 每次都出结果表，可复现 |

**关键**：网页那条路径之前走不通，是因为本地 80 亿参数的小模型不会做工具编排。
换成 DeepSeek 云端模型后**完全打通**——模型会自己去读技能文档、调用工具、取回结果。

## 二、开录前准备（10 分钟）

### 1. 启动两个服务（各一个黑框，**全程别关**）

**黑框 A —— 计算服务**

```
node "$env:USERPROFILE\Desktop\DS Harness\work\solarglyph-skill\solarglyph-core\server.js"
```

看到 `listening on http://127.0.0.1:8787` 即成功。

**黑框 B —— 网页服务**

```
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Desktop\DS Harness\work\reports\start-gateway.ps1"
```

等 10—15 秒。

### 2. 打开网页并登录

浏览器打开：`http://127.0.0.1:18789/`

要填令牌就填：`solarglyph-demo-2026`

### 3. 确认 Skill 已装

双击桌面 → **`录视频-镜头2.bat`**

看到 `Skills (23/59 ready)` 和 ☀️ `solar-glyph-simulation` 即可。

> ⚠️ 顺序很重要：**先双击镜头2 装好技能，再录网页那段**。如果先跑了镜头1（卸载），网页里就看不到技能了。

### 4. 让对话界面干净

网页里点一下 **新会话**，或者用一个没聊过天的会话，避免历史记录干扰画面。

### 5. 屏幕弄干净

- 黑框字号调大（`Ctrl` + 滚轮）
- 退出微信 / QQ / 钉钉，开专注助手
- 浏览器 `Ctrl+Shift+B` 隐藏书签栏
- **检查桌面有没有带学校名字的文件**

## 三、录制大纲（5 段，约 4 分 20 秒）

### 第 1 段｜"原版不会"（50 秒）

**操作**：双击桌面 → `录视频-镜头1.bat`

**屏幕**：`Skills (21/57 ready)`，没有 solar

**念**：

> 工业厂区屋顶光伏项目，方案阶段要回答两个问题：一年能发多少电？余热还能回收多少？
> 目前靠人工查气象数据、套 Excel 公式，慢，而且没法复现。
> 这是没有做任何扩展的原版 OpenClaw，自带五十多个能力，没有任何一个能算光伏或余热。这就是我们要解决的问题。

**念**：

**然后**：打开文件管理器进 `work\solarglyph-skill`，鼠标依次点这几个文件：

**念**：

> 这是计算引擎，负责光伏发电和余热回收的算法。

### 第 3 段｜⭐【核心】在网页里一句话跑完仿真（90 秒）

**画面**：浏览器 `http://127.0.0.1:18789/`，进入一个干净会话

**操作**：在对话框输入下面这句，回车：

```
启动光伏余热仿真
```

**然后等约 20 秒，不要动鼠标**。

**屏幕上会出现**：
1. 模型显示"运行了 2 个命令，读取了一个文件"
2. 然后输出一张完整的中文结果表

**你念（在等待时先说）**：

> 我在 OpenClaw 的网页对话框里只说了一句中文：启动光伏余热仿真。
> 请注意，我没有告诉它要执行什么命令、用什么脚本——它自己判断出该用哪个技能，
> 自己去读了技能文档，然后调用工具把仿真跑起来。

**结果表出来后停 5 秒**，再念：

> 它完成了一次完整的仿真，并且给出了结果：五兆瓦装机，年发电四百九十九点五万度，
> 余热年回收三百一十五点二万度，其中余热发电三十七点八万度，年减排二氧化碳一千七百七十六吨。
> 整个链路是：自然语言 → 智能体决策 → 调用技能 → 仿真服务计算 → 结果返回。

**操作**：再输入下面这句，回车（证明是活算）

```
换成 1MW 的厂房场景重跑一遍
```

**念**：

> 我再换个场景试试。它同样自动完成了仿真，数字随之改变——
> 说明这是真实的计算，不是提前写好的答案。

**操作**：切到黑框，跑这条命令展示服务端留痕

```
Invoke-RestMethod http://127.0.0.1:8787/v1/simulations?limit=8 | Select-Object -ExpandProperty jobs | Format-Table createdAt,status,presetId -AutoSize
```

**念**：

> 这是仿真服务自己的任务记录，刚才两次对话产生的任务都在里面，任何人都可以核对。

## 五、遇到的问题怎么办

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 网页说"计算服务连不上" | 黑框 A 被关了 | 重开，跑启动命令 |
| 网页打不开 | 黑框 B 没起来 | 重跑启动命令，等 15 秒 |
| 要填令牌 | 正常 | 填 `solarglyph-demo-2026` |
| 网页里技能列表看不到 solar | 技能被卸了 | 双击 `录视频-镜头2.bat` |
| 模型回复"模型不可用" | 模型名被改错 | 告诉我，我改回 `deepseek/deepseek-v4-pro` |
| 模型反问"你要做什么" | 对话历史太乱 | 新开一个会话再试 |
