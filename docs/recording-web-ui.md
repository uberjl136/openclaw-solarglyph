# 录视频大纲（已实测版）：展示 OpenClaw + 我们的 Skill

> **这份大纲里每一条命令都是我在本机实际跑过的。**
> 网页里用自然语言触发那一条，我测了多次**没有成功**，所以大纲里如实标注了 —— 详见第一节。

## 一、先说清楚：哪条路能走通

| 方式 | 实测结果 | 视频里用不用 |
| --- | --- | --- |
| OpenClaw **识别并加载**我们的 Skill | ✅ 网页和命令行都能看到 `✓ ready` | **用**（这就是集成成功的证据） |
| **命令行**触发 Skill 跑完仿真 | ✅ 每次都成功，出完整结果表 | **用**（这是自动化闭环的证据） |
| **网页对话框**里说「启动光伏余热仿真」 | ❌ 本地 8B 小模型不调用工具，会反问"请提供命令名" | 不用，但**如实说明** |
| 网页里 `/skill solar-glyph-simulation ...` | ❌ 报 `Tool not available: exec`（这条路径在网页端被权限层拦住） | 不用 |

**网页那条为什么不行**：它要求模型自己想到"去读技能文档，再决定跑什么命令"。本地 80 亿参数的小模型做不到这一步。日志显示模型确实被调用了、也正常返回了（5 秒），只是它不肯调用工具。

**这不是 Skill 的问题**——技能已被 OpenClaw 正式识别为 `ready`。换成云端模型（DeepSeek / OpenAI / 通义等）这条就通了。

> **如果你的团队有云端大模型的 API Key**，告诉我，我帮你接上——那样网页对话就能真正自动跑通，视频会更漂亮。
> 没有也完全不影响：下面的大纲同样能证明"Skill 装进 OpenClaw 后，自动化流程能跑完"。

## 二、开录前准备

### 1. 启动两个服务（各占一个黑框，全程别关）

**黑框 A —— 计算服务**

```
node "$env:USERPROFILE\Desktop\DS Harness\work\solarglyph-skill\solarglyph-core\server.js"
```

看到 `listening on http://127.0.0.1:8787` 即成功。

**黑框 B —— 网页服务**

```
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Desktop\DS Harness\work\reports\start-gateway.ps1"
```

等约 15 秒。浏览器打开 `http://127.0.0.1:18789/`，要填令牌就填：

```
solarglyph-demo-2026
```

双击桌面 → `录视频-镜头2.bat`，看到 **`Skills (23/59 ready)`** 和 ☀️ 那一行即可。

### 3. 屏幕弄干净

- 黑框字号调大（按住 `Ctrl` 滚鼠标滚轮）
- 退出微信 / QQ / 钉钉
- 浏览器 `Ctrl+Shift+B` 隐藏书签栏
- **检查桌面有没有带学校名字的文件**，有就挪走

### 第 4 段｜⭐ 跑完一次完整仿真（70 秒，核心）

**操作**：切到黑框 C（新开一个），先粘贴这一行进入项目目录：

```
cd "$env:USERPROFILE\Desktop\DS Harness\work\solarglyph-skill"
```

再粘贴这一行并回车：

```
node scripts/trigger.cjs "启动光伏余热仿真"
```

**屏幕会依次出现**：任务提交 → 进度 25% → 50% → 70% → 90% → 100% → 结果表

**念**：

> 这是一句中文指令触发的。可以看到它先识别出这是光伏余热仿真，自动选用了五兆瓦工业厂区场景，
> 然后向仿真服务提交任务、拿到任务号，接着是真实的轮询过程：加载输入、换算光照、求解发电和余热、汇总结果。
> 整个过程走的是真实的 HTTP 接口，不是写死的数字。

**结果表出来后停 5 秒**，再念：

> 结果出来了。五兆瓦装机，年发电四百九十九万度，余热年回收三百一十五万度，
> 其中余热发电三十七万度，年减排二氧化碳一千七百七十六吨。

**再跑一个场景证明是活算**：

```
node scripts/trigger.cjs "西北高辐照 10MW"
```

**念**：

> 换个场景再跑一次，数字跟着变了，说明背后是真实的工程计算。

**如实说明**（重要，避免评委以为在藏问题）：

> 补充说明：这条链路是 OpenClaw 的 Skill 通过工具调用驱动的。
> 网页对话框里用纯自然语言触发需要更大的模型，本机用的八十亿参数小模型做不到稳定编排，
> 所以演示用的是同一个 Skill 的确定性入口，保证结果可复现。
