# 佐证材料

本目录是参赛作品的**佐证材料**，用于证明两件事：**做出来了**（真实性）、**确实有效**（效果）。

材料全部由**实际运行产生**，不是文字描述：日志是命令的真实输出，截图是真实浏览器
访问本机服务的画面，仓库数据取自 GitHub 官方 API 与本地 git。

## 三、材料之间的交叉验证关系

这不是一堆孤立文件，同一个事实有多条独立证据链：

**「模型自己调用了技能」**
- 截图 `03` 显示对话里出现「**运行了 2 个命令, 读取了一个文件**」，然后是完整指标
- 该次对话产生的任务号 `6c86a36f` 出现在截图 `05` 的服务端任务记录里
- 截图 `05` 是浏览器直接访问 `http://127.0.0.1:8787/v1/simulations` 的原始 JSON，
  带 `createdAt`、`durationMs`、`presetId`，不是模型自述

**「数字是算出来的，不是写死的」**
- 四个场景结果互不相同（`01-测试记录.md` 表格），容量/辐照/余热热源都变
- `logs/03` 记录了 5%→25%→50%→70%→90%→100% 的真实轮询轨迹，每步耗时 400ms

**「没有改上游源码」**
- `git log --oneline -- upstream/` 只有 1 个提交，提交信息标注 `unmodified`
- 技能以新增目录方式装进工作区，上游目录零改动（`02-仓库与提交记录.md`）
