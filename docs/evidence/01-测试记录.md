**这七项分别防的是什么**：

| 检查 | 防的问题 |
| --- | --- |
| SKILL.md 的 name/description | 技能元数据不合规，框架无法加载 |
| 5 个运行时文件与源一致 | 技能里那份副本被手改过，与源脱节 |
| 技能内引擎可独立加载 | 技能依赖仓库其他目录，装到别处就跑不了 |
| 两次运行结果一致 | 结果有随机性，不可复现 |
| 未知请求返回退出码 2 | 触发词匹配过于宽松，乱说话也会触发 |
| 未知命令返回退出码 2 | 命令行静默接受错误参数 |
| 在线端到端跑通 | 只有单元测试通过、接上真实服务就坏 |

## 九、复现这些测试

前提：仿真服务在 `127.0.0.1:8787` 运行。

```bash
# 在仓库根目录执行
npm start                 # 另开一个终端，保持运行
npm run verify-skill      # 对应第 1 项
npm run smoke             # 对应第 2 项
npm run test:e2e          # 对应第 3 项
node scripts/trigger.cjs "启动光伏余热仿真"     # 对应第 4 项
node scripts/trigger.cjs "西北高辐照 10MW"      # 对应第 5 项
npm run check             # 一次跑完 1+2
```

> `scripts/trigger.cjs` 与 `skills/solar-glyph-simulation/scripts/trigger.cjs` 是同一份文件
> （自检第 2 项就校验这一点），用哪个都一样。
